How to Upload 300 Wallpapers
1

Upload to Cloudinary (Free)

Go to cloudinary.com → Media Library → Upload All 300 images at once (bulk upload supported). After upload, each image gets a permanent URL like res.cloudinary.com/your-id/image/upload/v1/cars/ferrari-roma.jpg

2

Export URL List as CSV

In Cloudinary → Media Library → select all → Export → choose CSV. This gives you a spreadsheet with all image URLs already filled in.

3

Fill Metadata in Sheets

Open the CSV in Google Sheets. Add columns: title, brand, category, resolution. Fill them in — you can do 300 rows in one session. Use Data → Autofill for repeated values like resolution.

4

Import Here → Export Code

Download as CSV from Google Sheets, drop it into this tool. Switch to the Export Code tab and copy the generated constants.ts — paste it directly into your project. Done.

5

Sitemap Auto-Updates Too

The sitemap in the Export tab is also auto-generated from your data. Replace velocitywalls.com with your real domain and drop it in your project root.
